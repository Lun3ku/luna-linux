# Packages built from the AUR and signed with the Luna key, exactly like our
# own ones. They end up in the [luna] repository, which is what the installer
# uses, so they install on the target system with everything else.
#
# Why they are here at all: neither is in the Arch repositories, and both are
# things the system is expected to have. Building them ourselves is the only
# way to put them on a machine that has just been installed and does not yet
# have an AUR helper - which is a particularly circular problem in yay's case.
#
# These PKGBUILDs are somebody else's code, and makepkg runs them. That is the
# ordinary bargain of the AUR; the -bin variants are chosen partly for that
# reason, since they unpack a released binary instead of building from source.
# Both are checked against the sha256 sums in their own PKGBUILD by makepkg.
#
# Building them needs network access. LUNA_SKIP_AUR=1 skips this step.

yay-bin              # the AUR helper itself
localsend-bin        # sending files to a phone over the local network
